# RepoLens Client

Frontend single-page application for RepoLens, built with React 19, Vite, Bootstrap 5, and React Flow.

## Scripts

- `npm run dev` — Start Vite development server on http://localhost:5173
- `npm run build` — Build production assets into `dist/`
- `npm run preview` — Locally preview the production build
- `npm run lint` — Run ESLint

## Environment

Configure `VITE_API_BASE_URL` in `.env` (defaults to `http://localhost:5000/api`).
Never expose backend API keys or database secrets in the client environment.
